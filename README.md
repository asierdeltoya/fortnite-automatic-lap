# fortnite-automatic-lap
自動でプレイやロビーに戻るを押させるツール

# これは何？
ロビーの「プレイ」→ マッチ中の「続行」→ 結果画面の「スキップ」→
「ロビーに戻る」を自動でクリックして、周回を繰り返すツールです。
画面を見てボタンを探してクリックしているだけで、ゲームの内部データ
には一切触れていません。

# 使い方
1. pk-auto.exe をダブルクリックして起動します（exe 単体で動きます。
   他のファイルは不要です）管理者で実行しないと正常に動かない場合あり。
2. Fortnite を起動し、ロビー画面を表示しておきます。
3. pk-auto のウィンドウで「開始」を押します。
4. 止めたいときは「停止」ボタンか、F8 キー。もう一度 F8 を押すと再開します。

# モード説明

### モード A：通常ループ

マッチを最後まで進めて、結果画面を抜けるまでを繰り返します。

| 手順 | 押すボタン |
|:---:|---|
| 1 | ロビーの **プレイ** |
| 2 | マッチ中は待機 |
| 3 | **続行** |
| 4 | **スキップ** |
| 5 | **ロビーに戻る** → 1 に戻る |

- マッチ中は、WASD のどれかをランダムに長押しします（初期値は10秒ごとに3秒）
- 長押しの入り切り、間隔、長押し秒数は、画面で変えられます。

### モード B：待機島ループ

待機島で一定時間待ってから、メニューを使って自分でロビーに戻ります。マッチを最後まで遊びません。

| 手順 | 動作 |
|:---:|---|
| 1 | ロビーの **プレイ** を押す |
| 2 | 待機島に入ったら、設定した秒数だけ待つ（初期値 **90秒**） |
| 3 | **`Esc`** キーを押す |
| 4 | 右上の **≡**（横3本線）を押す |
| 5 | **ロビーに戻る** を押す → 1 に戻る |

- 待ち時間は、画面の「B: 待機島で ○ 秒待ってから Esc」で変えられます（10〜600秒）。
- バーやメニューの形で画面を見分けるので、**どの言語でも動きます**。
- Bの間は、WASD の長押しは動きません。

### モード C：宝箱を探す

マップを歩き回り、金色の宝箱を見つけると近づいて **E** で開けます。
画面を読むだけで、ゲームの内部データには触れません。

| 手順 | 動作 |
|:---:|---|
| 1 | ロビーの **プレイ** を押す |
| 2 | マップを歩き、視点を回して宝箱を探す |
| 3 | 宝箱を見つけたら近づいて **E** |
| 4 | 10個開けるか10分たったら、ロビーに戻って次の試合へ |

### モード C：宝箱ルート farming（完全自動）

マップ画像に宝箱の場所を書いておくと、バスから飛び降り、マップを開いて
自分の位置を確認し、宝箱を順番に回って開け、また次の試合を始めます。
止めるまでこれを繰り返すので、何時間でも放置できます。

**準備（初回だけ）**
1. 宝箱の場所が書かれたマップ画像を `assets\chest_map.png` として保存します。
2. ゲーム内でマップを開き、「画像を切り抜く」の一覧で **map_player** を選び、
   白いプレイヤーの矢印を囲んで保存します。
3. マップを開いた状態で **「マップを確認」** を押すと、`assets\map_check.png`
   に認識結果（島の範囲・矢印・ルート）が保存されます。

**動き方**
- バスから飛び降り、マップを開いて着地を確認します。
- マップ上の矢印の位置から、宝箱までの方角と距離を計算して走ります。
- 走るたびにマップを開き直して位置を補正するので、多少ずれても戻ります。
- 宝箱の近くで画面を見て宝箱を探し、**E** で開けます。開けた数は画面に
  表示されます。
- ルートを回り終えるか、マッチが終わるか、15分たつとロビーに戻って
  次の試合を始めます。
- 壁に引っかかるとジャンプして横に避けます。

**注意**
- ゲーム内マップは**ズームも移動もせず、島全体が見える状態**にしてください。
  地図の位置合わせは島の形と大きさを使っています。
- ストームの位置は分かりません。圏外なら倒されてロビーに戻り、また
  次の試合を始めます。
- 宝箱は金色で見つけます。「画像を切り抜く」で **chest** を選んで宝箱を
  保存すると、金の武器などを誤って開こうとしなくなります。
- 準備ができていないときは、これまで通り「歩き回って宝箱を探す」動作に
  なります。

### モードの違い

| | モード A | モード B | モード C |
|---|---|---|---|
| 1周の長さ | マッチが終わるまで | 約2分（待機秒数＋移動） | 10個 or 10分 |
| マッチを最後まで遊ぶ | する | しない | しない（宝箱探し） |
| WASD 長押し | する | しない | 自分で歩く |


# 設定について
- しきい値スライダー：ボタンの認識精度です。反応しないときは少し
  下げてみてください（誤作動が増える場合は上げてください）。
- 「マッチ中 WASD ランダム長押し」：オンにすると、マッチ中に
  W/A/S/D のいずれかをランダムに一定時間押し続けます。間隔と長押し
  秒数は画面上で変更できます。
- 画面サイズやUIが違ってボタンを認識しない場合は、「画像を切り抜く」
  ボタンでご自分の画面から撮り直せます（exe の横に assets フォルダが
  作られ、そちらが優先されます）。
- 「宝箱を確認」：今の画面で宝箱を見つけられるか試します。見つからない
  ときは「画像を切り抜く」で **chest** を撮り直してください。
- 設定（言語・モード・しきい値・画面など）は exe の横の
  pk-auto-config.json に自動で保存され、次回起動時に復元されます。
- 画面が複数あるときは「画面」で Fortnite を表示している画面を選びます。
